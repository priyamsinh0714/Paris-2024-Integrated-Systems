# Paris Olympic Games 2024: Database and Analytics Project

## Overview
This project focuses on designing and implementing a structured database for managing various aspects of the Paris Olympic Games 2024. It also includes data-driven insights and recommendations to enhance operational efficiency and reduce costs.

## Project Details
- **Part A: Database Design and Implementation**
  - Created an Entity-Relationship Diagram (ERD) using Chen’s notation.
  - Developed a relational database using SQL to manage:
    - Event scheduling and venue allocation.
    - Athlete accommodations based on team, sport, and nationality.
    - Equipment and resource tracking, including inventory and maintenance.
    - Volunteer assignments and training schedules.
  - Populated the database with dummy data to simulate real-world scenarios.

- **Part B: Data Analytics Report**
  - Used SQL queries to extract insights and identify operational challenges.
  - Proposed data-driven recommendations for improving event management.
  - Highlighted areas for reducing costs and enhancing efficiency.

## Key Features
1. **Database Design:** ERD and schema for comprehensive event management.
2. **SQL Implementation:** Tables, relationships, constraints, and dummy data.
3. **Data Analysis:** SQL queries for extracting actionable business insights.
4. **Business Recommendations:** Data-driven strategies for better resource utilization and cost savings.

## Tools & Technologies
- **Database Management:** SQL
- **Data Analytics:** SQL Queries
- **Visualization:** ERD using Chen's notation
- **Documentation:** Report detailing findings and recommendations
